# little-prince-raspberry-reader
本项目基于树莓派，创建了一个小王子阅读陪伴助手，将树莓派与玩偶进行衔接后，可以通过对玩偶实施动作使得网页页面进行变换。

本系统以《小王子》为故事背景，基于树莓派3B与PICO2双芯片协同的嵌入式架构，构建面向儿童的情绪陪伴交互系统。

系统采用无显示屏设计：树莓派3B作为主控单元，通过摄像头采集儿童面部图像，调用百度AI人脸表情识别API获取情绪标签（happy、surprise、sad、neutral）。PICO2作为感知辅助芯片，通过GPIO串口（杜邦线连接树莓派GPIO14/15与PICO2的UART0）与树莓派通信，负责MPR121电容触摸检测（拍头、拍背、捏耳朵）和APDS-9960手势与接近检测（手靠近召唤狐狸、上下左右手势识别）。

树莓派运行Python后端服务，接收PICO2发来的触摸和手势信号，并结合情绪识别结果，经WebSocket协议实时推送到客户端浏览器前端页面。前端基于Three.js和Canvas 2D技术构建3D/2D交互场景，实现以下功能：

情绪识别映射天气：开心对应晴天、惊讶对应星空闪烁、伤心对应打雷、中性对应默认天气，PICO2灯带同步变色；

物理触控响应：拍头触发3D星球降落动画、拍背触发云层转场进入2D游戏、捏耳朵触发小王子抬头显示随机语录；

手势控制：左右手势控制狐狸行走移动，上下手势触发烟花绽放和爱心飘浮特效；

狐狸召唤机制：首次手靠近APDS-9960接近传感器时召唤狐狸角色出现，并启用手势识别功能。

通过软硬件协同设计，系统为儿童提供了富有故事感和沉浸感的情绪表达与互动体验。
